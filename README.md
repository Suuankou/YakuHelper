# Yakuhelp

A Riichi Mahjong project.

## Requirements

- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/)

## Installation

Clone the repository:

```bash
git clone git@github.com:Suuankou/yakuhelp.git
cd yakuhelp/client
```

Install dependencies:

```bash
pnpm install
```

## Running

Start the development server:

```bash
pnpm dev
```

## Building

```bash
pnpm build
```
